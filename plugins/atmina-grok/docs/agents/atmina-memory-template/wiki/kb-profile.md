# Knowledge Base profile

**Intensity:** middle (the default). Durable claims about the world carry
typed evidence. Unlocated claims are Open Questions. A locator that does not
resolve is a stop, not a guess.

**Scope:** organisation.

This file is the Knowledge Base profile. It is not an evidence-type registry.
